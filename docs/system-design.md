# 系統設計

## 訂位流程

旅客選擇日期與方向 → 查詢航次 → 選擇票種與人數 → 填寫旅客資料 → 確認訂位 → 產生訂單編號。

## 核心模型

routes
- 航線，例如布袋港 → 澎湖、澎湖 → 布袋港

ships
- 船舶基本資料與載客量

trips
- 某一天實際營運的航次，包含日期、時間、船舶與可售數量

ticket_types
- 成人、兒童等票種與價格

orders
- 訂單主檔、訂位人、狀態與總金額

order_items
- 每種票的數量與單價

order_passengers
- 訂單內每位旅客資料

## 訂位安全

建立訂單時必須使用資料庫 transaction，並在確認剩餘座位後才扣除可售數量，以避免多人同時訂位造成超賣。

## 暫不包含

- 線上信用卡／第三方金流
- 實體座位選位
- 複雜會員制度
